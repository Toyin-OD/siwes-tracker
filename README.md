# SIWES Tracker

A web application built with PHP, MySQL, HTML, and CSS to help students manage and track their SIWES applications.

## Features

* User registration and login
* Add and manage SIWES applications
* Edit and delete applications
* Track application statuses
* View application statistics on the dashboard
* Monitor application deadlines

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* XAMPP

## Local Setup

1. Install XAMPP and start Apache and MySQL.
2. Place the project folder inside your XAMPP `htdocs` directory.
3. Open phpMyAdmin and create a database named `siwes_tracker`.
4. Import `siwes_tracker.sql` into the new database.
5. Copy `includes/database.sample.php` to `includes/database.php`.
6. Update the database connection settings if necessary.
7. Open the project in your browser at `http://localhost/siwes_tracker/`.

## Note

This project was developed as a portfolio project to practise PHP, MySQL, and full-stack web development.
